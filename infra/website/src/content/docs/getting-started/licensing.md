BreachLine is free to install and use for opening, querying, and visualising data. A license unlocks the collaboration features: workspaces, annotations, and sync.

## What a license unlocks

Without a license you can:

- Open CSV, XLSX, and JSON files (and whole directories).
- Run queries, sort, and use the timeline histogram.
- Copy selected rows to the clipboard.

A valid license additionally unlocks:

- Saving and opening workspaces.
- Adding annotations to rows.
- Syncing workspaces and annotations across machines.

## Purchasing a license

Buy a license from the [purchase page](/purchase/). Once payment completes, your license file is generated and emailed to the address you used at checkout.

The license is a single file. Keep it somewhere safe: you can re-import it on any machine where you run BreachLine.

## Activating your license

1. In BreachLine, choose **File → Import License**.
2. Select the license file you received by email.
3. BreachLine validates the file and stores it. The licensed features unlock immediately.

You can confirm the active license, including the registered email and expiry date, under **Help → About**.

## Expiry and renewal

Licenses are time-limited, an expired license stops unlocking the licensed features until you renew.

To renew, purchase again from the [purchase page](/purchase/) and import the new license file the same way.

## Moving to a new machine

Your license is not tied to hardware. Copy the license file to the new machine and import it with **File → Import License**. If you no longer have the file, re-download it from the original purchase confirmation email.

## Troubleshooting

If a license will not import, see [Troubleshooting](/docs/reference/troubleshooting/).
