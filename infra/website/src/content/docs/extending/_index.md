Extend BreachLine beyond its built in behavior: read formats it does not support out of the box through loader plugins, and let an external AI client drive the app over an MCP server.

- [Plugin System](/docs/extending/plugin-system/) - what plugins are and how to install one.
- [Plugin Developer Guide](/docs/extending/plugin-developer-guide/) - write a loader plugin in any language.
- [MCP Server](/docs/extending/mcp-server/) - let an AI client open files, run queries, and annotate in the live window.
