BreachLine has keyboard shortcuts for the actions you reach for most during an investigation. On macOS use **Cmd** where the table lists **Ctrl**.

## Grid navigation

| Shortcut | Action |
|---|---|
| `g` | Jump to the top of the grid |
| `Shift+G` | Jump to the bottom of the grid |

## Selection and copying

| Shortcut | Action |
|---|---|
| `Ctrl+A` | Select all rows matching the current query |
| `Ctrl+C` | Copy the selected rows as TSV |

See [Copying & Exporting](/docs/searching/copying-exporting/) for what gets copied.

## Files and views

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open a file |
| `Ctrl+,` | Open settings |
| `Ctrl+H` | Toggle the timeline histogram |
| `Ctrl` + backtick | Toggle the console panel |

## Search

Click the search bar or start typing to build a query, then press **Enter** to run it. See the [Query Language](/docs/searching/query-language/) guide.

You can also see this list any time from **Help → Shortcuts** inside the app.
