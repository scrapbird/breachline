# Download BreachLine

Every download is an archive. Extract it and run the application: there is no installer. See [Installation](/docs/getting-started/installation/) for step-by-step instructions.

## Windows
- [Download for Windows (x64)]() - `breachline-windows-amd64.zip`, containing `breachline.exe`, for Windows 10/11

## macOS
- [Download for macOS (Universal)]() - `breachline-macos-universal.tar.gz`, containing `breachline.app`, a single Universal build that runs natively on both Apple Silicon and Intel Macs

## Linux
- [Download for Linux (x86_64)]() - `breachline-linux-amd64.tar.gz`, containing the binary, for Ubuntu, Fedora, Arch, and other x86_64 distributions
